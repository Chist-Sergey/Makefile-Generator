# Setup

## Step 1.

Go to the file and download it raw, or you can download  
it directly via Terminal/Console with cURL/Wget.

Manual download:  
https://github.com/Chist-Sergey/Makefile-Generator/blob/master/src/genmakefile.py

cURL:

```bash
curl -LJO https://raw.githubusercontent.com/Chist-Sergey/Makefile-Generator/main/src/genmakefile.py
```

RHEL7.6:

```bash
wget https://raw.githubusercontent.com/Chist-Sergey/Makefile-Generator/main/src/genmakefile.py --output-document=genmakefile.py
```
